    const body = await r.text();

    console.log('body:', body.slice(0, 1400));
  } catch (e) { console.log('\n=== ' + label + ' ===\nERROR', e.message); }
}

--- WHAT THIS PROVES ---------------------------------------------------------

VERIFIED, 2026-08-27:
  GET https://graph.facebook.com/instagram_oembed?url=<public IG post>
  returns HTTP 200 with no access token, no Meta app, and no App Review.
  The versioned form (/v23.0/) behaves identically.
  The control (bogus shortcode) fails with
      {"error":{"message":"The requested resource does not exist","type":"OAuthException",
        "code":24,"error_subcode":2207045,"error_user_title":"Media Not Found",
        "error_user_msg":"The requested media could not be embedded either because it does not
        exist or you don't have permission to embed it."}}
  i.e. the failure is about the MEDIA, not about AUTH. Authentication is genuinely not the gate
  any more. Our previous claim -- "legacy oEmbed 301s to Graph oEmbed, which needs an app token
  plus App Review" -- is now FACTUALLY WRONG on the second half. The 301 is still real
  (api.instagram.com/oembed -> 302 -> www.instagram.com/oembed/), but the destination is open.

AND YET, UNAVAILABLE as a content source:
  the entire response body is

      version        1.0
      provider_name  Instagram
      provider_url   https://www.instagram.com/
      type           rich
      width          658
      html           <6,435-byte grey skeleton blockquote>

  There is NO `title`. NO `author_name`. NO `thumbnail_url`. NO caption anywhere.
  Stripping every tag from the 6,435-byte `html` leaves exactly five words of visible text:

      "View this post on Instagram"

  The `data-instgrm-captioned` attribute on the blockquote is an instruction to Instagram's own
  embed.js to fetch and render the caption client-side from Instagram's servers. The caption is
  not in the payload we receive.

  Contrast TikTok oEmbed (docs/04-tiktok-feasibility.md M1, VERIFIED), whose `title` field carries
  the full caption. That asymmetry -- not authentication -- is the reason Instagram stays out.
